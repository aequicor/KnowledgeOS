# Правило поиска информации

Всегда следуй этому порядку при поиске:

1. **KnowledgeOS MCP tools first** — всегда используй `knowledgeos_search_docs` для любых вопросов о документации, концепциях, гайдлайнах, архитектуре, решениях или конвенциях проекта. Vault — единственный источник истины.

2. **Читай возвращённые документы** — `search_docs` возвращает chunkId с `docPath`. Прочитай каждый уникальный `docPath` из `vault/` чтобы получить полный контент, прежде чем решать, нужно ли больше информации.

3. **Только потом код** — если `search_docs` ничего не дал И чтение документов не помогло, используй grep/glob/read для поиска по коду.

4. **Документируй новое** — если обнаружил что-то важное, чего нет в vault, используй `write_guideline` чтобы это записать.
